# 1-stdin.js Program

## Overview

This is a simple Node.js program that prompts the user for their name and then displays a greeting message with their input. The program works both interactively through user input and through piping input from a file or command.

The program performs the following actions:
1. Displays the message: `Welcome to ALX, what is your name?`
2. Accepts user input for their name.
3. Displays the message: `Your name is: <input>`
4. When the program ends, it displays the message: `This important software is now closing`.

## Requirements

- Node.js (v14.x or higher recommended)

## Files

- **1-stdin.js**: The main program that implements the functionality described above.
